# Surface: app window (ui/index.html)

Mode: Operate. Glance between matches (Alt+Tab in the lobby), Portuguese, Brasília time.

## Direction contract

THESIS: The companion reads as the Fortnite lobby itself: saturated lobby-blue field, heavy condensed caps, rarity-framed item tiles and a shop-style refresh timer, so a player tabbing in knows where everything is. It refuses the generic grey dark-card dashboard of v0.1.

OWN-WORLD: Lobby blue field (deep navy to royal blue radial, faint diagonal light streaks), one Fortnite yellow for the primary action and live states, white type, rarity gradients (uncommon green, rare blue, epic purple, legendary orange, mythic gold) only on item tiles. Anton caps for numbers and titles, slanted like the game's headers; Barlow Semi Condensed for UI. Parallelogram tabs, chips and buttons; drawn line icons in one stroke.

STORY: In seconds the player sees how many chests count (and that it matches the game), when the next Treasure Hour is, which prizes are still missing and the odds of already having the token, then goes back to the match.

FIRST VIEWPORT: Top bar: mark + tabs PAINEL, PRÊMIOS, AGENDA, CONTA with icons; refresh at right. Left: chest tile with the count at display scale, a "confere com o jogo" status, today and rate. Right: Treasure Hour tile with countdown, yellow when live. Below: the week's prizes as an item-shop row of rarity tiles with art, owned ones stamped, a "sai em" timer. Odds tile with three scenario bars.

FORM: Brief-pinned world (user asked for a Fortnite-like panel with official item art), overriding the rolled assignment; seed:341b55f23575643c. Signature move: the item-shop prize row with its refresh timer.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
